Introduction

Netflix publishes its What We Watched reports to provide greater transparency about how audiences engage with content on its streaming platform. These reports show the viewing performance of movies, television series, and other content, helping creators, investors, and industry analysts understand audience preferences and viewing trends. This analysis combines seven six-month reports, covering January 2023 through June 2026, to examine Netflix’s content performance over time. The purpose of this report is to analyze Netflix’s viewing data and provide strategic recommendations to Netflix leadership regarding content investment decisions and beyond. The analysis examines viewing patterns, catalog size, popular titles, international availability, and differences between content formats. These findings can help identify which types of content generate sustained engagement and where Netflix should prioritize its future investments.

Task 1: Acquire Netflix’s seven reports

The following code can be used to acquire data from Netflix’s corporate relations website. Specifically, once run, this code will download and aggregate the previous seven WWW reports. Netflix provides slightly different data from each report, so this function standardizes on a small set of key features including: the ‘watch window’, the title of the program, the runtime, the total hours viewed, the original release date of the program, whether the program is available in all countries in which Netflix is available, and whether the program is pre-recorded or live.

To be efficient, this function will save a copy of the downloaded data in a folder called data/mp01 and use that copy to avoid re-downloading a file if it is already present on your computer. This will make your code faster to run and will avoid putting unnecessary stress on the Netflix servers.

#' Acquire Netflix What We Watched Reports (instructor-provided code)
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

# Gini coefficient: G = 2 * sum(i * y_(i)) / (n * sum(y)) - (n + 1) / n,

  x <- sort(x[is.finite(x) & x >= 0])

  if (n == 0L || sum(x) == 0) return(NA_real_)

}

Executive Summary

Netflix’s seven What We Watched reports suggest that the company should balance major original productions with consistently popular series and internationally accessible content. These findings indicate increased engagement with reported content, although they do not necessarily reflect subscriber growth or profitability.

Blockbuster Hits and Consistent Favorites

Popular franchises attract substantial audiences, but viewing is spread across many titles. The ten most-watched titles represented 5.3% of total hours in 2023H1 and 6.7% in 2026H1. The share peaked at 8.0% in 2025H2. Bridgerton: Season 4 generated 889.8 million hours in 2026H1, demonstrating the value of established franchises.

However, older series also provide consistent engagement. Breaking Bad: Season 2 averaged 91.6 million hours across seven periods and never fell below 78.5 million hours. Titles such as Money Heist and Suits showed similar durability. Netflix should therefore invest in both new blockbuster productions and established series that continue attracting viewers over time.

Viewing Concentration and the Gini Coefficient

The Gini coefficient measures how unevenly viewing is distributed across titles. A value closer to zero indicates more equal viewing, while a value closer to one indicates greater concentration.

The hours-based Gini increased from 0.737 in 2023H2 to 0.755 in 2026H1, suggesting a modest increase in concentration. We use 2023H2 as a more comparable baseline because the earlier report has substantially different data coverage.

To account for differences in content length, we also examined implied views, calculated using viewing hours divided by runtime. The implied-views Gini increased from 0.700 in 2023H2 to 0.709 in 2026H1. The Lorenz curves and Gini trend chart illustrate how viewing remains concentrated among relatively few titles. Netflix should monitor both major hits and the wider catalog when making investment decisions.

Globally available titles accounted for 38.2% of reported titles in 2026H1 but generated 49.1% of viewing hours. This suggests that widely accessible content plays an important role in Netflix engagement. However, global availability does not necessarily indicate international production or profitability. Investment decisions should also consider regional audience preferences and licensing costs.

Release timing can significantly affect viewing totals. ## Memorandum: Original Content Spending in 2027 and Beyond

**To:** Netflix Executive Leadership  
**From:** Content Strategy and Analytics  
**Subject:** Recommendations for Original Content Investment

### Executive Summary

Netflix's seven *What We Watched* reports suggest that the company should balance major original productions with consistently popular series and internationally accessible content. Reported viewing increased from **64.9 billion hours in 2023H2** to **74.3 billion in 2026H1**, while the number of reported titles grew from **6,574 to 8,163**. These findings indicate increased engagement with reported content, although they do not necessarily reflect subscriber growth or profitability.

### Blockbuster Hits and Consistent Favorites

Popular franchises attract substantial audiences, but viewing is spread across many titles. The ten most-watched titles represented **`r percent(memo_top10_first, accuracy = 0.1)`** of total hours in 2023H1 and **`r percent(memo_top10_last, accuracy = 0.1)`** in 2026H1. The share peaked at **8.0% in 2025H2**. *Bridgerton: Season 4* generated **889.8 million hours** in 2026H1, demonstrating the value of established franchises.

However, older series also provide consistent engagement. *Breaking Bad: Season 2* averaged **91.6 million hours** across seven periods and never fell below **78.5 million hours**. Titles such as *Money Heist* and *Suits* showed similar durability. Netflix should therefore invest in both new blockbuster productions and established series that continue attracting viewers over time.

### Viewing Concentration and the Gini Coefficient

The **Gini coefficient** measures how unevenly viewing is distributed across titles. A value closer to zero indicates more equal viewing, while a value closer to one indicates greater concentration.

The hours-based Gini increased from **0.737 in 2023H2** to **0.755 in 2026H1**, suggesting a modest increase in concentration. We use 2023H2 as a more comparable baseline because the earlier report has substantially different data coverage.

To account for differences in content length, we also examined implied views, calculated using viewing hours divided by runtime. The implied-views Gini increased from **`r number(memo_gini_views_base, accuracy = 0.001)`** in **`r gini_base`** to **`r number(memo_gini_views_last, accuracy = 0.001)`** in 2026H1. The Lorenz curves and Gini trend chart illustrate how viewing remains concentrated among relatively few titles. Netflix should monitor both major hits and the wider catalog when making investment decisions.

### International Availability and Release Timing

Globally available titles accounted for **`r percent(q5_global_title_2026, accuracy = 0.1)` of reported titles** in 2026H1 but generated **`r percent(q5_global_hours_2026, accuracy = 0.1)` of viewing hours**. This suggests that widely accessible content plays an important role in Netflix engagement. However, global availability does not necessarily indicate international production or profitability. Investment decisions should also consider regional audience preferences and licensing costs.

Release timing can significantly affect viewing totals. *I Will Find You: Limited Series* accumulated **350.5 million viewing hours** during just **13 days** of availability in 2026H1, averaging approximately **27 million hours per day**. Netflix should therefore evaluate both total viewing hours and viewing rates adjusted for the number of days a title was available.

### Live Events and Recommendations

Live events represented only **`r percent(memo_live_last, accuracy = 0.1)`** of total viewing hours in 2026H1. Although average live-event performance was comparable to pre-recorded content, the ten leading pre-recorded entries averaged **107.5 million implied views**, compared with **11.3 million** for the top ten live events. This suggests that live programming should complement, rather than replace, successful scripted content.

For 2027 and beyond, Netflix should prioritize five actions:

1. Continue investing in successful franchises while developing new original content.
2. Maintain consistently popular series that provide long-term engagement.
3. Expand internationally appealing content based on regional demand and performance.
4. Invest selectively in live events.
5. Evaluate content using implied views, release-adjusted viewing rates, audience retention, and production costs.

Overall, Netflix should pursue a balanced strategy that combines major releases with dependable catalog content while using viewing data and financial measures to guide future investments.
